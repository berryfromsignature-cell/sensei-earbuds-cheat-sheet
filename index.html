<Requirements>

  • Hardware: Mac (Apple Silicon) + iPhone or Android + earbuds (mic + media).
  • AI stack: Claude Pro (with Claude Code) + ChatGPT Plus or Team.
  • Orchestration: Sensei (kosuke.ai) via MCP. Agents on Mac. Audio on phone.
  • Network: Tailscale (private tailnet between Mac and phone).
  • Optional: GitHub and Linear and Notion and Telegram for artifacts and alerts.

<Setup>

  • Join Mac and phone to the same Tailscale tailnet. Confirm both devices are online.
  • Connect Sensei as an MCP server in Claude Code and ChatGPT.
claude mcp add --transport http kosuke https://app.kosuke.ai/api/mcp
# ChatGPT: Settings → Developer mode → Add MCP → https://app.kosuke.ai/api/mcp
  • On the Mac run the Sensei event bridge (streams agent events to your phone):
npx @kosuke/sensei-bridge --events --tailscale --project viral-study
  • On the phone: install Sensei → enable Voice Mode → set earbuds as audio output.

<Workflow>

  • Define a high-level objective in Sensei (target and context and guardrails) by voice or app.
  • Sensei breaks it into a plan and routes work to Claude Code or Codex or ChatGPT on the Mac.
  • The Mac executes. The bridge sends structured events over Tailscale to Sensei.
  • Sensei converts high-signal events into short audio in your earbuds (not raw logs).
  • You control the run with Voice Mode and earbud gestures. No terminal UI required.

<Run signals>

  • INIT Run opened on the Mac. MCP session and repo and tools are ready. You hear one line that you are live. No Terminal.
  • PLAN Spoken step list before any code runs. Wrong plan? Say “stop” and state a new objective.

State order on the bridge:

INIT → PLAN → (TOOL)* → CHECKPOINT* → BLOCK? → REVIEW? → OBJECTIVE → IDLE

INIT payload:

{
  "type": "INIT",
  "run_id": "run_8f2a",
  "agent": "claude-code",
  "spoken": "Session live on viral-study repo."
}

PLAN payload:

{
  "type": "PLAN",
  "steps": ["repro flake", "patch auth.ts", "npm test", "open PR"],
  "spoken": "Four steps before merge."
}
  • TOOL Optional. One line per tool call only if verbose mode is on.
  • CHECKPOINT A step finished. You hear what changed and where outputs live and what is next.

CHECKPOINT payload:

{
  "type": "CHECKPOINT",
  "summary": "Tests green after auth.ts patch",
  "artifacts": ["branch fix/flake-auth"],
  "next": "open PR against main"
}
  • BLOCK Mac waits for you. Merge deploy secrets or policy gates need a voice answer.
  • REVIEW Spoken gate before production ship. Scope risk and recommended yes or no.

BLOCK payload:

{
  "type": "BLOCK",
  "reason": "policy",
  "needs": "approve_merge",
  "spoken": "PR 142 ready. Approve or deny?"
}
  • OBJECTIVE Goal done. PR link or report path plus any queued follow-ups.
  • IDLE No active run. Bridge stays up. Long-press for a new job. Single-tap for status.

TTS filter (what never hits your ears):

drop: raw_stderr · tool_stdout · stack_traces
keep: PLAN · CHECKPOINT · BLOCK · REVIEW · OBJECTIVE

<Voice interface>

  • Control Pause resume stop continue or rollback without opening the Mac.

Control intents:

sensei.control.pause()
sensei.control.resume()
sensei.control.stop(graceful=true)
sensei.control.rollback(steps=1)
  • Routing Point the next chunk at Claude Code or ChatGPT or Codex.

Routing intents:

sensei.route.set(agent="claude-code")
sensei.route.set(agent="chatgpt")
sensei.route.set(agent="codex", paths=["src/auth/**"])
  • Context Load profile shards and attached docs so every tool call stays on brief.

Context intents:

sensei.context.use(profile="viral-study")
sensei.context.attach(["brand.md", "playbook.md"])
sensei.context.shard(batch=12)
  • Actions Ship work from speech. You hear CHECKPOINT or BLOCK only when needed.

Action phrases:

"open a PR with today's changes"
"merge if CI is green"
"deploy preview"
"send summary to Telegram"
  • Introspection Replay structured state if you missed audio. Not terminal scrollback.
  • Scheduling Cron objectives. Earbuds get OBJECTIVE or BLOCK when the job ends.

Status and schedule phrases:

"what's the current state"
"read the plan again"
"why is it blocked"
"run this ingest every Monday 6am"
"notify me when PR checks pass"

<Earbud controls>

Default gesture bindings:

gesture.single_tap    = sensei.status.checkpoint
gesture.double_tap    = sensei.tts.mute_toggle
gesture.triple_tap    = claude.session.interrupt
gesture.long_press    = voice.capture.inject
gesture.hold_double   = run.cancel(flush=true)
  • Single tap Pull the latest CHECKPOINT. Step last change and whether the agent waits on you. Works when TTS is muted.

Status readout shape:

{
  "spoken": "Checkpoint 3 of 4. Tests passed. Waiting: none.",
  "step": "open PR",
  "blocked": false
}
  • Double tap Mute or unmute all Sensei speech. Mac keeps executing in the background.
  • Triple tap Hard interrupt on Claude Code. Use when the run is off track. Then long-press with a clearer goal.

Interrupt side effect:

claude.session.interrupt()
→ run.state = BLOCK | IDLE
→ spoken = "Session stopped. Long-press for new instruction."
  • Long press Open Voice Mode mic. Your line becomes the next user message for a new task or a BLOCK answer.

Voice inject examples:

"approve merge on PR 142"
"use branch hotfix/auth only"
"stop and run tests only"
  • Hold + double Cancel the run and flush the in-flight plan. Return to IDLE. Git commits already pushed remain in the repo.

Sensei app path:

Settings → Earbuds → Gestures → Sync to phone

<Guardrails>

Persistent project profile in Sensei. Same repo and stack and limits every run.

Create profile:

/profile new --name viral-study --repo <url> --stack claude,chatgpt

System instructions:

"You are my autonomous research operator. Objective: analyze short-form video at scale (4,812,506 TikToks) and surface what drives virality. Constraints: never merge without approval. Never make payments without approval. Never exfiltrate raw creator data. Request approval for high-risk steps. Process: plan and shard workloads and write features and summaries. Outputs: concise Checkpoints and diffs and links and next actions for audio. Not stack traces."

Attach reference docs:

/profile attach --docs brand.md playbook.md study.md

Policy layer:

/policy set --deploy=confirm --cost>$0=confirm --pr=auto --data=readonly

<Operating loop>

  • Start a run with one clear objective or a saved Sensei template.
  • Listen for PLAN and CHECKPOINT and BLOCK and OBJECTIVE on your earbuds.
  • Approve or redirect or stop with voice or earbud gestures.
  • Close with a results summary and the next recommended batch or task.
  • Iterate weekly. Update profile and guardrails and attached docs when the playbook changes.
